# カラオケ点数管理

JOYSOUND・DAMのカラオケ採点結果を記録・管理するWebアプリです。

曲ごとの点数を一覧で確認したり、検索・絞り込み・並び替えを行うことができます。

## 🌐 Webアプリ

**カラオケ点数管理**

https://quickfox7.github.io/karaoke-score-manager/

## ✨ 主な機能

### 🔍 検索

以下の項目を対象に検索できます。

- 曲名
- 曲の読み
- アーティスト名

### 🎯 絞り込み

以下の条件で曲を絞り込むことができます。

- **すべて**
  - 登録されているすべての曲
- **JOYSOUNDあり**
  - JOYSOUNDの点数が記録されている曲
- **DAMあり**
  - DAMの点数が記録されている曲
- **両方あり**
  - JOYSOUND・DAMの両方に点数が記録されている曲
- **未記録**
  - JOYSOUND・DAMともに点数が記録されていない曲
- **90点以上**
  - JOYSOUNDまたはDAMで90点以上を記録した曲

各絞り込み項目には、該当する曲数が表示されます。

### 📊 ソート

曲名、JOYSOUND、DAM、最高点の項目をクリックして、並び順を切り替えることができます。

- 曲名順
- 曲名逆順
- 最高点が高い順
- 最高点が低い順
- JOYSOUNDが高い順
- JOYSOUNDが低い順
- DAMが高い順
- DAMが低い順

現在選択しているソート方向は、`⬇️` / `⬆️` の矢印で確認できます。

### 🎤 点数管理

曲ごとに以下の点数を管理できます。

- JOYSOUNDの点数
- DAMの点数
- JOYSOUND・DAMの最高点

点数の登録・編集・削除にも対応しています。
